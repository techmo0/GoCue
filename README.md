# GoCue

Учебный проект команды «Диалог»: мобильное приложение, которое сохраняет намерение и напоминает о нём тогда, когда пользователь действительно оказался в подходящем месте. Например, «Купить молоко» с контекстом MY_SUPERMARKET появляется после подтверждённой остановки в выбранном супермаркете, а не в назначенное время и не сразу после пересечения геозоны.

## Границы MVP

Локальное хранение без аккаунта, сервера и LLM; создание и завершение намерений; физические и семантические места; ручная привязка MY_SUPERMARKET; фоновая геозона; подтверждение визита по времени нахождения; одна групповая нотификация за визит; Remind next visit; журнал событий и экран симуляции. Логика намерений получает нормализованный ContextSnapshot, а не координаты GPS.

Целевая мобильная платформа (Android или iOS) ещё не выбрана командой. Реальный геофенсинг будет проверяться после доменного прототипа и симуляции. Дедлайны, маршрутизация, поиск магазинов, облачная синхронизация и распознавание текста не входят в MVP.
