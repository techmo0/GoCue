# Редактируемые диаграммы ЛР2

Восемь исходников диаграмм (`.mmd` и `.puml`) — **редактируемые файлы проекта**, не скриншоты. UML Use Case, развёртывание и компоненты построены в PlantUML с каноническими обозначениями; остальные схемы — в Mermaid. Папка `rendered/` содержит SVG и PNG для встраивания в технический проект и документы для портала.

| Файл | Вид |
| --- | --- |
| `01-context.mmd` | Контекстная |
| `02-use-case.puml` | UML Use Case — варианты использования |
| `03-class.mmd` | UML классов |
| `04-deployment.puml` | UML развёртывания |
| `05-components.puml` | UML компонентов |
| `06-activity.mmd` | UML деятельности |
| `07-state.mmd` | UML состояний (выбранный вариант) |
| `08-er.mmd` | ER-модель |

Все схемы относятся к **проектируемой** Android-системе, а не к уже работающему приложению. Описание элементов, ограничений и связь с требованиями — в [`Технический_проект.md`](../Технический_проект.md).
