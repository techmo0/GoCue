# Редактируемые диаграммы ЛР2

Все восемь исходников диаграмм — `.puml`, то есть **редактируемые файлы PlantUML**, не скриншоты. UML-схемы используют соответствующие типы диаграмм PlantUML; ER выполнена в нотации Information Engineering (crow's foot). Папка `rendered/` содержит SVG и PNG для встраивания в технический проект и документы для портала.

| Файл | Вид |
| --- | --- |
| `01-context.puml` | Контекстная |
| `02-use-case.puml` | UML Use Case — варианты использования |
| `03-class.puml` | UML классов |
| `04-deployment.puml` | UML развёртывания |
| `05-components.puml` | UML компонентов |
| `06-activity.puml` | UML деятельности |
| `07-state.puml` | UML состояний (выбранный вариант) |
| `08-er.puml` | ER-модель |

Все схемы относятся к **проектируемой** Android-системе, а не к уже работающему приложению. Описание элементов, ограничений и связь с требованиями — в [`Технический_проект.md`](../Технический_проект.md).
