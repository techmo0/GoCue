# Редактируемые диаграммы ЛР2

Восемь файлов `.mmd` — **исходники проекта диаграмм**, не скриншоты. Их можно открыть в редакторе Mermaid или править как текст; GitHub показывает Mermaid в Markdown. Папка `rendered/` содержит SVG для встраивания в технический проект и документы для портала.

| Файл | Вид |
| --- | --- |
| `01-context.mmd` | Контекстная |
| `02-use-case.mmd` | UML Use Case — варианты использования |
| `03-class.mmd` | UML классов |
| `04-deployment.mmd` | UML развёртывания |
| `05-components.mmd` | UML компонентов |
| `06-activity.mmd` | UML деятельности |
| `07-state.mmd` | UML состояний (выбранный вариант) |
| `08-er.mmd` | ER-модель |

Все схемы относятся к **проектируемой** Android-системе, а не к уже работающему приложению. Описание элементов, ограничений и связь с требованиями — в [`Технический_проект.md`](../Технический_проект.md).
