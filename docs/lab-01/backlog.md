## Предлагаемый Definition of Done

Результат удовлетворяет критерию задачи, лежит в репозитории, просмотрен другим участником и сопровождается применимыми тестами. Для геосценариев зафиксированы условия проверки и ограничения устройства. Секреты, реальные траектории и личные данные не публикуются; статус доски меняется только после фактического выполнения.
